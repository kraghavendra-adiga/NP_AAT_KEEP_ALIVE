Client 0: heartbeat interval vs hidden NAT timeout

Grey line = the NAT's real (hidden) timeout for this client. Coloured line = how long the server waits before the next heartbeat. Red triangles = drops. The interval should climb toward, but stay under, the grey line. After a drop the NAT swallows the server's close, so the client only notices through its 15-minute silence watchdog and the line stays flat until it reconnects. How to read this

Each coloured card is one policy running on its own set of real TCP connections with the same seed (same message arrivals, same NAT). Heartbeats/client-hour is the overhead; drops are connections the NAT killed before the server noticed. The adaptive policy has to find the timeout by trying longer intervals, so it may cause a few drops while learning.
